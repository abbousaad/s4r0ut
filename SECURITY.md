# Security Policy

s4r0ut is a defensive password-pattern research project. Please report issues
that could expose private data, encourage misuse, or weaken the integrity of the
generated releases.

## Report Privately

If you find private credentials, personal data, or a sensitive leak in this
repository, do not open a public issue containing the data. Contact the
maintainer privately and include only enough context to locate and remove the
problem.

## What To Report

- Private credentials or account dumps
- Personal identifiers tied to real individuals
- Data that appears to come from unauthorized collection
- Build or QA bypasses that allow unsafe data into releases
- Documentation that could reasonably encourage misuse

## Scope

This project does not provide offensive support. Reports should focus on
protecting users, improving defensive research quality, and maintaining clean
data provenance.
