# Source Notes

s4r0ut is built from curated cultural and linguistic seed categories, then
expanded through deterministic rules. The project does not accept private leaks,
account dumps, or personal data tied to identifiable individuals.

## Seed Categories

- `names_morocco.txt`: Moroccan first names and spelling variants.
- `family_names_morocco.txt`: common Moroccan family names and name particles.
- `darija_latin.txt`: Darija words commonly written in Latin script.
- `cities_regions.txt`: Moroccan cities, regions, and common informal spellings.
- `football_culture.txt`: Moroccan football and national-team references.
- `amazigh_hassaniya_latin.txt`: Amazigh, Hassaniya, and regional Latin-script terms.
- `keyboard_patterns_morocco.txt`: keyboard and weak-password patterns seen in local contexts.
- `institutions_culture_morocco.txt`: public institutions, brands, and cultural motifs.
- `moroccan_patterns.txt`: reusable numeric and Morocco-specific password motifs.

## Curation Rules

- Prefer Morocco-specific signal over generic volume.
- Use lowercase ASCII where possible for compatibility with common tools.
- Keep seeds reusable; generation rules create variants.
- Avoid real phone numbers, IDs, emails, usernames, or exposed credentials.
- Document every new seed category before it is used in a release profile.
